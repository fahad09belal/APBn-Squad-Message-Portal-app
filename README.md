## Overview

Project Froyo: APBn Squad Message Portal is an Android client crafted by Fahad Al-Belal for dedicated, fast access to the squad messaging network.

Designed following the retro desktop aesthetics of the APBn Squad and PhalqonOS ecosystem, this client integrates real-time web socket messaging with Android native system notifications and offline reliability.

### Key Features
- **Dedicated Fullscreen Portal:** Seamless WebView optimized for APBn Squad with custom styling, high responsiveness, and zero distraction bars.
- **Native Real-Time Notification Pipeline:** Message interception delivers exactly one native alert per message with the custom APBn message icon.
- **Offline XP Desktop:** Standalone offline suite (`offline.html`) containing interactive windows, draggable dialogs, taskbar integration, and developer profiles.
- **Automatic Recovery:** Integrated network monitor with `Android.retryConnection()` bridge for seamless reconnects once network connectivity is restored.
- **Froyo Build Standards:** Native Material theme with custom Android vector assets and multi-density mipmaps.
